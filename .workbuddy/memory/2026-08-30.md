## fix(错题本总结页)：下次复习时间表"线不平"

### 用户反馈
截图显示 `#quiz-wrongbook` 总结页里的「📅 下次复习时间表」列与列之间没有清晰竖线，且列宽随内容自适应，导致视觉上边框歪歪扭扭、横线不平。

### 根因
`.wb-next-table` 没有 `table-layout: fixed`，各列宽度由每行内容决定；题目列文字长度不一，导致整列边界看起来抖动。同时单元格只有行下边框、没有列边框，进一步放大了"线不平"的感觉。

### 修复（index.html `.wb-next-table` CSS）
1. 加 `table-layout: fixed`，让列宽由表头/列宽规则统一决定。
2. 给 5 列分别固定宽度并居中（题 46px / 题目 auto / 结果 58px / 盒级 108px / 下次复习 96px）。
3. `td` 增加 `border-left: 1px solid var(--border)`，第一列去除，形成笔直竖线。
4. `th` 下边框从 1px 加到 2px，视觉更重、更稳。
5. `td/th` `vertical-align` 从 `top` 改为 `middle`，内容垂直居中，横线更平。
6. 题目 `.qi` 去掉 `max-width:520px`，改 `min-height: 2.8em`，保证单行题目也能占满两行高度，避免行高忽高忽低。

### 验证
用 Chrome headless 对提取的 `.wb-next-table` 静态测试页截图，竖线笔直、横线水平、列宽一致。

## feat(错题本·按盒查看)：顶部 pill 支持点击筛选

### 用户反馈
截图显示「按盒查看」顶部的盒级统计 pill（盒1/盒2/…/已毕业）不能点击，用户希望点击后只显示对应盒子的题目。

### 实现（index.html）

  - `all`：显示盒1-5 + 已毕业；

  - `'graduated'`：只显示已毕业卡片。

## 跨设备打卡日历同步断裂 · CloudBase 云函数欠费（2026-08-30）

- 用户反馈："打卡日历的数据在别的电脑上有，本机不展示"。截图为公网版（learningDesktop/index.html），热力图徽章 `已完成 12/182，最长 12 天` → 表明 localStorage 只有本机最近 12 天，云端 182 天没合并进来。
- 实测三段链路：
  - `tcloudbaseapp.com/` 静态页 → 200 OK
  - `…app.tcloudbase.com/syncProxy/v1/rdb/rest/user_data` → 400 `FUNCTIONS_INVOCATION_FAILED, AvailableStatus = InsufficientBalance`（欠费停服）
  - `…api.tcloudbasegateway.com/v1/rdb/rest/user_data` → 401 `MISSING_CREDENTIALS`（被云函数拦在前一步）
- 根因：CloudBase 云函数 `syncProxy` 欠费停服 → 跨设备同步链路断了 → `initCloud` 的 select 永远抛错 → `cloudReady=false` → 既拉不到云端历史、又拦截本地新卡上云。
- 修复路径：① CloudBase 控制台给 env `test-d5gf0o9ky7d34beaf` 充值 → ② 重启云函数 → ③ 确认 env `CLOUDBASE_SERVICE_KEY` 还在（service_role 开头、永久）→ ④ 本机 Ctrl+Shift+R 强制刷新页面触发 `initCloud` 重跑 `select+深合并` 把云端 182 天回写到 localStorage。
- 提醒：欠费停服期间所有设备的 `localStorage` 仍是断电后最后一次成功同步的快照，多设备间天然不可靠。建议给 CloudBase 加余额预警（控制台 → 费用中心），避免再次无声中断。
