## 热力图再次空白：根因是外部题库引入的 TDZ 错误（commit dbbe4b8）
- 用户反馈：首页「打卡日历」热力图又没了，统计全 0。
- 复现：当用户点击「🌐 外部题库打卡」后，`localStorage.setItem('cdga-quiz-mode','external')`；下次刷新时脚本在 `applyQuizMode()` 中调用 `renderExtBanks()`，而 `renderExtBanks` 引用的 `EXT_BANKS` 是用 `const` 在更后面（约 3962 行）定义的 → 触发 Temporal Dead Zone（TDZ）ReferenceError：`Cannot access 'EXT_BANKS' before initialization`。
- 后果：该错误在脚本执行早期抛出，后续 `buildHeat()` / `refreshHeat()` 等全部未执行 → 热力图空白、统计归零。
- 修复：把 `EXT_BANKS` + `EXT_BANK_STORE` 的定义前移到 `let quizMode=...` 之前（紧接 `QUIZ_STORE`），并在注释里说明必须先定义再初始化 quizMode。
- 验证（jsdom）：预置 `cdga-quiz-mode=external` 时不再报错；热力图 182 格正常渲染；若 `cdga-daily-checks` 有历史数据，打卡记录会正确恢复（不会清空）。
- 用户操作：刷新 http://192.168.103.37:8080/ 即可；若之前打卡数据仍在 localStorage，会自动恢复。

## 每日学习中心刷新后默认显示当天任务（commit 976fdfb）
- 用户反馈：每次刷新进去不是当天的任务，而是 2026-08-15。
- 原因：脚本末尾硬编码 `renderDay('2026-08-15')`，并且 `renderDay` 在找到有效日期时不会同步更新 `<input type=date id="dayDate">` 的值。
- 修复：
  - 将初始渲染改为 `renderDay(TODAY_ISO)`，刷新后自动落到当天。
  - 在 `renderDay` 中始终设置 `dayDate.value=iso`，确保日期选择器与显示内容一致。
- 验证（jsdom）：默认加载后 `dayDate.value` 与卡片标题均为系统当天（2026-08-17），无 JS 错误；外部题库模式（quizMode=external）下热力图仍正常渲染。
