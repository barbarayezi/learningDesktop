## 软考每日中心 UI 修复（2026-08-16 收尾 #2）
- 用户截图反馈软考每日中心"渲染草率"：打卡日历呈细长浅灰条、日期显示 Day1=2027-03-14（与配置 start 2027-03-15 差一天）、周芯片无当前周高亮。
- 根因：
  1. 热力图容器 `.gen-heat` 用了 `grid-template-columns:repeat(14,1fr)`，但 `.hl-cell` 固定 14×14px，导致每个 grid item 被拉宽、cell 只占左上角，呈现一堆空白长条。
  2. 日期函数 `genTodayISO`/`genAddDays` 用 `toISOString().slice(0,10)`，在 GMT+8 时区把本地 00:00 转成 UTC 前一天 16:00，导致所有日期少一天。
  3. 周芯片没有根据当前选中日在 `genRenderDay` 里更新 `active` 类。
- 修复：
  - CSS：`.gen-heat` 改为与 `.heat-grid` 同款 `grid-template-rows:repeat(7,14px);grid-auto-flow:column;gap:3px;width:max-content`，并共用 hover 效果；去掉三个 `.gen-heat` 的 inline grid 样式。
  - JS：日期函数改为 `new Date().toLocaleDateString('sv')` / `d.toLocaleDateString('sv')`，保证本地时区正确；新增 `genDiffDays(start,iso)` 替换原先基于 UTC 的 idx 计算。
  - JS：`genRenderDay` 里同步更新当前周芯片 `.active` 高亮；热力图 title 改为 `iso wd · Wn`、加 `data-w` 属性。
- 验证：node 本地测试 `genAddDays('2027-03-15',0)` → 2027-03-15 周一（与配置一致）；`new Function` 语法 OK。
- 待用户硬刷新浏览器查看，仍需手动 git commit。
