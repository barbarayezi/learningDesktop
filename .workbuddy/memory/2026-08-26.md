## 每日刷题「防重复」机制:第一遍优先抽未答过的题(2026-08-26)

- **用户痛点**(原话):"我现在感觉每日刷题会刷到重复的题目,要不搞个防重复机制,第一遍先把所有的题目尽可能全部刷到再说?"
- **根因(两层)**:
  1. `practiceList()`(line 3901)按 `今天+域+source+seed` 洗牌后**取前 N 道**,**完全不查重**。一个域 20 题 / 每天抽 5 道,2-3 天就能在前 5 位里碰上重复。
  2. `openQuiz(k,'practice')`(line 6248)**会清空 `practice.answers`**(原意是"每轮新开始"),所以即使第一遍答过,第二天进刷题时也已经忘了 → 第二天又按种子洗牌抽前 5,跟昨天大概率重复。
- **修复**:
  1. `practice` 新增 `antiRepeat:true`(默认开),`loadPractice/savePractice` 持久化。
  2. `practiceList()` 加 antiRepeat 分支:把池子拆成「未答 unans + 已答 done」,**先洗 unans 取前 N,不够再补 done**;整域都答过(20/20)才回退到原行为(洗整池取 N)。
  3. `openQuiz(k,'practice')` 在 antiRepeat 开时**不清空 answers、不加 todaySeed**,让"已答过"的状态在跨轮/跨日保留;关闭时保留原行为(清空+换种子)。
  4. 刷题页 HUD 加「🆕 防重复 开/关」一键切换按钮(对应 `btn-anti` 事件)。
  5. 每日卡片按钮文案三态:未答 → `🆕 刷题 ${name} ${done}/${cnt} 题 · 优先未答 · 每日抽 5`;今日已完成 → `✅ 刷题 ${name} 今日已刷题`;全答完一遍 → `🏆 复习 ${name} ${done}/${cnt} · 已全刷一遍`。
  6. 卡片底部在「仍有未答域」时显示一行防重复模式说明,可读性。
- **单元测试**(Node 6 场景全过):T1 全未答→5 道 / T2 答 0-4→新 5 道 / T3 答 0-17(剩 2)→2 未答+3 已答回退 / T4 全答完→回退原行为 / T5 跨日种子换 → 题完全不同 / T6 连续 4 天每天 5 道→累计 5→10→15→20(域内全覆盖)。

- **截图技巧备忘**:`puppeteer-core` 在沙箱里 `require('agent-base')` 长路径读不到(`\\?\C:\...` 失败);改用 `chrome --screenshot + _shoot.html iframe 入口`(同源 iframe + 预填 `localStorage._cdga_login` 绕过密码门)比 puppeteer 更稳。
