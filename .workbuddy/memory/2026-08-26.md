## 每日刷题「防重复」机制:第一遍优先抽未答过的题(2026-08-26)

- **用户痛点**(原话):"我现在感觉每日刷题会刷到重复的题目,要不搞个防重复机制,第一遍先把所有的题目尽可能全部刷到再说?"
- **根因(两层)**:
  1. `practiceList()`(line 3901)按 `今天+域+source+seed` 洗牌后**取前 N 道**,**完全不查重**。一个域 20 题 / 每天抽 5 道,2-3 天就能在前 5 位里碰上重复。
  2. `openQuiz(k,'practice')`(line 6248)**会清空 `practice.answers`**(原意是"每轮新开始"),所以即使第一遍答过,第二天进刷题时也已经忘了 → 第二天又按种子洗牌抽前 5,跟昨天大概率重复。
- **修复**:
  1. `practice` 新增 `antiRepeat:true`(默认开),`loadPractice/savePractice` 持久化。
  2. `practiceList()` 加 antiRepeat 分支:把池子拆成「未答 unans + 已答 done」,**先洗 unans 取前 N,不够再补 done**;整域都答过(20/20)才回退到原行为(洗整池取 N)。
  3. `openQuiz(k,'practice')` 在 antiRepeat 开时**不清空 answers、不加 todaySeed**,让"已答过"的状态在跨轮/跨日保留;关闭时保留原行为(清空+换种子)。
  4. 刷题页 HUD 加「🆕 防重复 开/关」一键切换按钮(对应 `btn-anti` 事件)。
  5. 每日卡片按钮文案三态:未答 → `🆕 刷题 ${name} ${done}/${cnt} 题 · 优先未答 · 每日抽 5`;今日已完成 → `✅ 刷题 ${name} 今日已刷题`;全答完一遍 → `🏆 复习 ${name} ${done}/${cnt} · 已全刷一遍`。
  6. 卡片底部在「仍有未答域」时显示一行防重复模式说明,可读性。
- **单元测试**(Node 6 场景全过):T1 全未答→5 道 / T2 答 0-4→新 5 道 / T3 答 0-17(剩 2)→2 未答+3 已答回退 / T4 全答完→回退原行为 / T5 跨日种子换 → 题完全不同 / T6 连续 4 天每天 5 道→累计 5→10→15→20(域内全覆盖)。
- **Chrome headless 截图**:`.workbuddy/test_screens/quiz_btns_zoom2.png` 清晰看到"刷题 数据质量 0/20 题 · 优先未答 · 每日抽 5" + 下方防重复说明文案。
- **截图技巧备忘**:`puppeteer-core` 在沙箱里 `require('agent-base')` 长路径读不到(`\\?\C:\...` 失败);改用 `chrome --screenshot + _shoot.html iframe 入口`(同源 iframe + 预填 `localStorage._cdga_login` 绕过密码门)比 puppeteer 更稳。
- **提交**:`feat(每日刷题): 默认开启防重复模式,每天优先抽未答过的题,全答完一遍自动毕业` —— push 到 main 后等 Actions 部署。

## 每日中心概念卡「答案:必考」bug 治本(2026-08-26 下午)

- **用户现象**(截图 + 原话):每日中心 W2 第一个概念卡展开答案后,红框显示「答案:必考」,根本不是题目答案。用户吐槽「这个答案你是怎么想的?答案是必考啊」。
- **根因**:`conceptPair()` 机械地把 `#cdga-check .chk-row span` 里第一个 `(`/`(` 括号内的任意内容都当答案。原清单文本里我写的 `（必考）`、`（每年必考）`是「考试重点标签」,不是答案本体 → 被拆成 `{q: 完整文本, a: '必考', hasAnswer: true}`。更严重的连带 bug:无括号的条目（如「数据治理与业务战略对齐」）`hasAnswer:false` 渲染「⚠ 此条清单无括号答案」,盲测失效;多括号条目(如「隐私影响评估（PIA）、合规（个保法/等保）」)后半段被丢弃。
- **修复**(方案 B,治本):
  1. **`conceptPair` 解析器升级**(line 5550-5602):
     - 新增 `_TAG_ONLY` 集合(必考/每年必考/必背/必看/重点/高频/常考/重要/核心/必考点/经典/基础/新增/新版新增/扩展考点/加分/P1/P2 等)和 `_NUM_RANGE_RE` 纯数字区间正则 → 命中时 `hasAnswer:false`,题面用全文,标签不丢
     - 多括号保护:括号后还有非空白内容时,剩余部分拼回题面(防丢字)
  2. **`#cdga-check` 清单 50 条全部规范化**(line 1522-1605,索引 0-49 不变,勾选状态按索引存 localStorage 安全):
     - **每条统一一条 `题面（答案）` 格式**,答案本体进括号,标签(必考/重点/高频等)放题面前或删除
     - **英文注释型**(`(Data Steward)`/`(Lineage)`/`(MDM)`/`(ER 图)`/`(DFD)`/`(PIA)`/`(Metadata Repository)` 等约 7 处)改为「题面:定义/职责/区别 + 答案:全要素」,不再被解析器当答案
     - **无括号条目** 全部补答案本体(如「三类元数据分别是什么（业务/技术/操作）」),确保 W2-W22 每天展示的概念卡都能正常盲测
     - **多括号条目**(`(PIA)` `、(个保法/等保)` 这种)合并为单括号,避免丢内容
  3. **不增删 `.chk-row`**:索引 0-49 顺序不变,用户已勾的检查状态安全。
