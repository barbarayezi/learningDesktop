## fix(刷题模式)：选项点击后停留在原题并显示反馈

### 用户反馈
"原创自测题选择完后不出现答案，直接跳到下一题了，而且也没有五道题就一轮结束了"

### 根因
`practiceList()` 在 `antiRepeat`（默认开启）下，每次都会重算 list：把"刚答完的题"从 `unans` 池挪到 `done` 池，并补到 list 末尾；同时从 `unans` 池里取下一道未答过的题填充到 `list[0]`。

旧代码在 `pc-opt` click handler 里 `savePractice(); renderPractice()`，renderPractice 又调 `practiceList()` → list 重排 → `currentIdx=0` 指向的是新的未答题（不是刚答的那道）→ 视觉上"跳到下一题"且永远停在 `currentIdx=0`，但底层的题一直在换。

→ 用户感觉：每答一题就跳到下一题，看不到 feedback，5 道题"飞速"答完。

### 修复（index.html 第 4167 行附近）
把 `savePractice(); renderPractice()` 改成 `savePractice(); revealAnswerFeedback(item, picked, list)`。

新增 `revealAnswerFeedback` 函数（不动 list、不前进 currentIdx），原地完成：
1. 把当前题选项 disabled + 加 `.locked` / `.correct` / `.wrong` 样式
2. 插入 `.pc-feedback` 块（✅/❌ + 解析）
3. 替换底部按钮为「下一题 →」/「查看成绩 →」（最后一题）
4. 更新 HUD 的 ✅对 / ❌错 + 进度条
5. 更新跳题小圆点样式

下次点「下一题」才进下一题（沿用原来的 `currentIdx++; renderPractice()`）。

### 验证
Puppeteer + 本地 Chrome headless 跑了端到端测试：
- BEFORE click: 第 1/5 题，4 选项未锁，无 feedback，底部「跳过」
- AFTER click: 题目文本不变 ✅、feedback 显示「❌ 回答错误，正确答案是 C 解析：…」 ✅、4 选项全锁 ✅、底部「下一题 →」 ✅
- AFTER next: 题号 第 1/5 → 第 2/5，新题目 ✅
