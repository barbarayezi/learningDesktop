## 打卡数据无法云端同步 · 根因（实测证据）

**用户反馈**：截图 cdga-daily 显示「已完 17/182、本期 3/7、打卡率 9%、连续 17 天」——本机 localStorage 有数据；换电脑看不到。

**关键事实**：
- `index.html` 已经预留公网同步代理：`SYNC_PROXY_URL = "https://test-d5gf0o9ky7d34beaf-1469471831.ap-shanghai.app.tcloudbase.com/syncProxy"`（不依赖家里 Mac 的设计意图）
- 实测该公网云函数 trigger URL 返回：
  ```
  HTTP 400
  {"code":"FUNCTIONS_INVOCATION_FAILED",
   "message":"Function is Unavailable, AvailableStatus = InsufficientBalance. (13e9cafe-...)"}
  ```
- **根因**：腾讯云 CloudBase 账户余额/欠费，云函数被冻结（`InsufficientBalance`），不是代码 bug
- 公网静态页 `tcloudbaseapp.com/` 仍是 HTTP 200，能正常 serve `index.html` —— 欠费只影响**云函数 / 容器 / 数据库查询等运行时能力**，静态网站托管不受影响

**`initCloud` 路径推断**：
1. 浏览器 fetch `SYNC_PROXY_URL` → 400 / InsufficientBalance → 抛错
2. catch 分支只 console.warn，不影响 UI：`cloudReady = false`
3. localStorage 拦截器 `if (!cloudReady) return` → 只写本地、不上传
4. → 当前电脑 localStorage 有数据（截图能看到），换电脑 localStorage 是空的 → 用户体感"换电脑看不到"

**历史经验回顾（参见 MEMORY.md）**：
- 2026-08-18 修复（commit 65e7d40）走的是"家里 Mac proxy_server.py 注入 service_role"路径；当时云端 `user_data` 表里已有 8/15-8/17 打卡数据（select 200 通过）
- 2026-08-25 把部署切到云函数（`cloudbase-sync-proxy/`），意图"告别家里 Mac 依赖"
- 但云函数现在欠费停摆，等于又"半坏"——所以用户才会说"目前的打卡数据不能云端同步了"

## 复习卡「一部分」按钮 bug 修复（commit 49b0d0e，已上线公网）

**用户反馈**：每日学习中心复习提醒点「⚠ 一部分」没反应。

**根因**：`index.html` line ~6439 原实现 `setCheckState(idx, false)` —— 把 checks[idx] 置 false，被 `dueReviewItems()` 的 `if(checks[k]!==true) return` 过滤，**该条概念永久退出复习池**（「一部分」形同「忘了」且无重学入口）；后面 `d[idx]=todayISO()` 写了个寂寞。Toast「按 3d 循环」是假的。

**修复**：`part` 分支改为 `setCheckState(idx, true)` —— 保留「已掌握」、mastered_at 重置为今天 → +3d 短周期再考，之后沿 3→7→14→30d 正常递进，与提示文案「退回短周期再练」对齐。

**验证链**（复用价值）：
1. node 模拟 `dueReviewItems`（注意：参数顺序 dates,checks,refISO；`toISOString()` 有 UTC 时区坑，模拟日期用本地格式化 `getFullYear()+'/'+...`）；修复前 checks=false → 各 +Nd 全空；修复后 +2/3/4d 按 cycle=3、+7d 推进 cycle=7
2. vm.Script 编译所有内联 <script> 查语法
3. 公网特征串验证：`curl -s 公网URL | grep -c '特征串'`（新注释/新调用为 1、旧调用只剩「忘了」分支 1 处）；**注意** GitHub 匿名 API 会 403 rate limit，可改用 WebFetch 查 `actions/runs` 确认 conclusion
4. 部署成功判据：公网 size 变化 + 新特征串 =1；run #43 部署产物已生效

**关联**：同日另有 commit `1643ca3`（Cloudflare Worker 版云同步代理，方案 C 落地，run #44），与本修复互不影响。
