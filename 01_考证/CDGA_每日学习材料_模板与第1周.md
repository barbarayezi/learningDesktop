# CDGA 每日学习材料（模板 + 第 1 周成品）

> 用法：每天按「目标 → 阅读 → 术语 → 自测 → 打卡」五步推进。模板可复制到任意周套用；下方已填好 **W1（2026-08-15 ~ 08-21）** 七天成品，你直接照做即可。

---

## 📐 每日学习卡片模板

```
【日期】YYYY-MM-DD  周次 Wx  第 x 天
【今日目标】一句话说明今天要搞定什么
【看课】B站搜当天知识域讲解（20–30min），先听建立直觉
【阅读/任务】结合课程精读教材/做笔记（30–40min）
【术语卡】今天新记的 1–2 个易混词（写定义+区别）
【自测】从 CDGA_原创自测练习题.md 抽 1 题，写出答案与理由
【打卡】✅ 完成 / ❌ 跳过（备注原因）
【明日预告】……
```

## 🗓️ 第 1 周（W1 · 2026-08-15 ~ 08-21）每日材料

### Day 1（8/15 周六）— 启动筹备
- **目标**：把"考试信息"和"资料清单"吃透，下定节奏。
- **任务**：读 `CDGA_资料获取清单.md` 与 `CDGA_数据治理工程师_复习规划.md` 第一节；记下行程与费用。
- **术语卡**：CDGA = Certified Data Governance Associate（数据治理工程师）；DMBOK2R = 第二版修订版教材。
- **自测**：CDGA 考试满分与及格分分别是？（答：100 分 / 60 分及格，时长 100 分钟，100 道单选）
- **打卡**：✅

### Day 2（8/16 周日）— 下单教材
- **目标**：正版教材下单，确认是「修订版」。
- **任务**：京东/当当自营搜《DAMA 数据管理知识体系指南（第二版修订版）》下单；核对封面副标题。
- **术语卡**：修订版 vs 旧版——修订版新增数据伦理/隐私/AI 伦理，约 10% 新题。
- **自测**：2025 年 6 月起 CDGA 启用哪版教材？（答：DMBOK2R 第二版修订版）
- **打卡**：✅

### Day 3（8/17 周一）— 官方信息源
- **目标**：锁定报名与大纲来源。
- **任务**：微信关注「MyDAMA」；浏览 DAMA 中国官网考试通知；确认 2027/3 场次与考点城市（北上广深等，满 25 人开考）。
- **术语卡**：MyDAMA = DAMA 中国报名/成绩/续证入口公众号。
- **自测**：CDGA 一年考几次、大致月份？（答：4 次，3/6/9/12 月当月末周末）
- **打卡**：✅

### Day 4（8/18 周二）— 建复习主页
- **目标**：用 GitLab Pages 搭复习主页（契合你的网页交付偏好）。
- **任务**：建 `cdga-review` 仓库；把规划 md 推上去，配 `.gitlab-ci.yml` 出 Pages；主页挂导图/术语表占位。
- **术语卡**：GitLab Pages = 静态站点托管，自动构建预览复习进度。
- **自测**：为什么用网页而非 Excel 交付复习进度？（答：可自动更新+git 提交，便于追踪与分享）
- **打卡**：✅

### Day 5（8/19 周三）— 术语表框架 v1
- **目标**：建 17 域术语框架，先列易混对。
- **任务**：建 `术语表.md`，先填：治理/管理、架构/建模、ETL/ELT、主数据/参考数据、业务/技术/操作元数据。
- **术语卡**：治理 ⊂ 管理（治理=决策监督，管理=执行）。
- **自测**：数据治理与数据管理的关系是？（答：治理是管理的一部分，负责决策与监督）
- **打卡**：✅

### Day 6（8/20 周四）— 题库/大纲资料 + 建课程清单
- **目标**：明确题库合法来源，备好自测题，并整理好 W3 起要跟的 B站课程。
- **任务**：
  1. 读 `CDGA_原创自测练习题.md` 结构；若已报名，把官方大纲/样题存入 `资料/` 子目录。
  2. **搜课建单**：B站搜 `CDGA` / `数据治理工程师` / `DAMA DMBOK`，挑 1–2 个 UP 主的自制讲解（看播放量+评论筛选，避开"网盘PDF/搬运付费课"），收藏进"CDGA"播放列表，W3 起每天看一节。
- **术语卡**：参考数据 = 受控词汇表（如代码表）；主数据 = 核心业务实体（如客户/产品）。
- **自测**：参考数据与主数据的区别？（答：主数据是核心业务实体，参考数据是用于分类的受控值集）
- **打卡**：✅

### Day 7（8/21 周五）— 周复盘 + 思维导图框架
- **目标**：完成 W1 收尾，画出 17 域思维导图骨架。
- **任务**：用 Xmind/Markdown 画 17 域一级框架（高分域标红、中分域标黄、低分域标绿）；周末自检打勾。
- **术语卡**：17 域三档——高(治理/质量/元数据/数仓/主数据/建模)、中(架构/安全/大数据/成熟度)、低(其余 7 域)。
- **自测**：17 域中哪 6 个属高分域？（答：数据治理、数据质量、元数据管理、数据仓库与BI、参考/主数据、数据建模与设计）
- **打卡**：✅ 周末自检：教材已下单 ✅ / 场次已定 ✅ / 仓库已建 ✅ / 术语表 v1 完成 ✅
