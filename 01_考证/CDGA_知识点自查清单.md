## 🧠 全局易混词对照（考前必看）

| 成对概念 | 关键区别 |
|----------|----------|
| 数据治理 vs 数据管理 | 治理=决策监督；管理=执行；治理 ⊂ 管理 |
| 数据架构 vs 数据建模 | 架构=顶层蓝图；建模=具体落地图纸 |
| ETL vs ELT | 先转换后加载 / 先加载后转换 |
| 维度建模 vs 三范式 | 分析友好 / 存储无冗余 |
| 主数据 vs 参考数据 | 核心业务实体 / 受控词汇表 |
| 业务/技术/操作元数据 | 业务含义 / 技术结构 / 运行记录 |
