# DAMA 三级进阶规划 · CDGA → CDGP → CDGE（含 CDAM / CDMP）

> 用途：把现有 26 周 CDGA 单一规划扩展为**长期进阶路径**，让考证不只停在初级。
> 编写日期：2026-08-14 · 信息源：DAMA 中国 MyDAMA 公众号、DAMA 授权机构公告、DGBOK 平台说明（2025–2026 公开规则）。

## 3. CDGP 备考全攻略（你未来半年的重点）

### 3.1 报名条件速查
| 学历 | 须持 CDGA | 数据管理工作年限 |
|---|---|---|
| 博士 | ✅ | 无要求 |
| 硕士 | ✅ | ≥ 1 年 |
| **本科** | **✅** | **≥ 3 年** |
| 专科 | ✅ | ≥ 5 年 |

> ⏰ 关键节奏：**通过 CDGA 后立即规划 CDGP**，中间不要等太久，否则容易把 DMBOK 细节忘掉。

### 3.2 题型与时间分配（130 分钟）
| 部分 | 题型 | 题数 | 单题分 | 小计 | 建议用时 |
|---|---|---|---|---|---|
| 第一类 | 单选 | 10 | 1 | 10 | 10 分钟 |
| 第二类 | 多选 | 15 | 2 | 30 | 30 分钟 |
| 第三类 | 论述题 | 5–6 | 10 | 60 | 90 分钟（每题 15–18 分钟） |
| **合计** | | **30–31** | | **100** | **130 分钟** |

### 3.3 论述题六大主题（按出题概率排序）
1. **数据治理体系顶层设计**（DG 委员会 / 角色 RACI / 战略对齐）
2. **数据质量场景化治理**（根因分析 + 六维度 + 改进闭环）
3. **元数据与数据血缘**（业务/技术/操作元数据 + 影响分析）
4. **主数据与参考数据**（MDM 实施模式 + 主数据治理案例）
5. **数据架构与建模**（分层 + 维度/范式 + 数据资产目录）
6. **数据安全与合规**（分类分级 + 脱敏 + 个保法 / 数据安全法）

> 📌 论述题特征：必做、不可选题，每题都要写满。所以 **6 个主题都要深入准备**。

### 3.4 备考三阶段（90 天）
- **D1–D30 知识关联**：不再按域孤立记忆，画一张「DMBOK 知识域关联图」（治理 × 质量 × 元数据 × 架构 × 安全 的交叉点）
- **D31–D60 案例沉淀**：搜集 2–3 个行业案例（建议：①电网主数据 ②银行数据质量 ③政务数据共享），每个案例写成 500 字「问题–方法–效果」
- **D61–D90 模拟训练**：至少 2 次完整模拟（130 分钟），重点练**时间分配 + 论述结构**（建议结构：①问题诊断 ②方法论 ③实施路径 ④风险与衡量）

### 3.5 论述题答题模板（15 分钟版）
```
1. 现象诊断（2 分钟）
   - 拆题目给出的业务场景，识别 1-2 个核心矛盾

2. 方法论框架（4 分钟）
   - 引用 DMBOK 对应知识域的核心概念
   - 画出 RACI / 六维度 / 分层 等结构化表达

3. 落地路径（5 分钟）
   - 短期：第 1 个月做什么
   - 中期：3 个月内做什么
   - 长期：6 个月-1 年做什么

4. 风险与衡量（2 分钟）
   - 列 2-3 个风险 + 1 组量化指标

5. 案例引用（2 分钟）
   - 用你的案例库 / 项目经验佐证
```

## 4. CDAM 同步备考（增值项）

为什么建议你**并行考 CDAM**：
- 内容与 CDGA/CDGP **重叠度 60%+**（数据资源盘点、确权、入表、价值评估）
- 但额外覆盖**数据资产入表**（财政部 2023 年新规）、《数据资产管理知识体系指南》
- 你做的是电网数据治理 + 申请在职博士，**论文方向「数据资产价值评估」可直接用**

### 4.1 CDAM 考试范围（当前复习清单）
- 数据资产管理理论（4 单 + 3 多）
- **我国数据要素理论**（4 单 + 3 多）⭐ 政策热点
- 数据资源盘点（4 单 + 2 多 + 2 论述）
- 数据资产确权（4 单 + 2 多）
- 数据资产价值评估（4 单 + 2 多）⭐
- **数据资产入表**（4 单 + 2 多）⭐
- 数据资产交易（4 单 + 2 多 + 1 论述）
- 数据资产利益分配（2 单 + 1 多）
- 数据资产运营（4 单 + 1 多 + 1 论述）含公共数据
- 数据资产跨境流通（3 单 + 1 多）
- 数据资本化（3 单 + 1 多）
- **论述题 2 题，从 3 道大题中选 2 题作答**（一般集中在入表、价值评估、跨境/运营）

### 4.2 备考策略
1. 把 DMBOK 高分域（治理 / 质量 / 元数据）当作基础
2. 补充「数据要素 × 数据资产入表」专题（财政部 2023 年 8 月《企业数据资源相关会计处理暂行规定》、2024 年各地入表案例）
3. 论述题可选 2 题优势：避开你最弱的「跨境流通」专攻「入表 + 价值评估」
4. 报名建议：**2027-06 或 2027-09 与 CDGP 一起报**，形成双证开局

## 5. CDGE（DGBOK 体系）路径

CDGE 是另一条赛道——**DGBOK 知识体系**，与 DMBOK 互补。CDGA 拿到后**不必重考**，直接可参加 DGBOK 统考。

### 5.1 CDGE 三级
| 级别 | 名称 | 条件 | 适用 |
|---|---|---|---|
| Steward | 数据治理专员 | 16+ 周岁，无学历要求，统考 ≥ C | 入门 / 转行 |
| Professional | 数据治理工程师 | ≥ 3 年数据治理经验，统考 ≥ A 或（≥ C + 1 门专业 ≥ C） | 进阶 |
| CDO | 首席数据官 | ≥ 5 年经验，统考 ≥ C + 2 门专业 ≥ C | 管理层 |
| M / G 级 | 大师 / 院士 | 职业履历鉴定 + 资历评审 | 资深顾问 |

### 5.2 CDGE 教材与平台
- 平台：**dgbok.org.cn**（数据治理专业等级认证统一考试平台）
- 教材：《DGBOK 数据治理知识体系指南》（出版中）+ 《简明数据治理手册》（过渡）
- 辅助：《一本书讲透数据治理》《数据治理之论》《DAMA-DMBOK2》
- 报名费：考试 500 + 认证 100 = **600 元 / 次**
- 形式：150 道选择题，**线上机考，远程监考，随时约考**

### 5.3 你的节奏建议
- **2028-07**：先报一次 CDGE-Steward（成本低、复习轻、当练兵）
- **2029**：拿 CDGE-Professional（结合 3 年+ 项目经验）
- **2030+**：评估 CDO 评审或转向 CDMP 国际版

## 6. CDMP 国际版（如果你以后进外企或走学术）

CDMP 是 DAMA 国际颁发，**全英文机考**，适合国际化背景。

| 级别 | 条件 | 难度 |
|---|---|---|
| Associate | 无 | 入门 |
| Practitioner | Associate + 1 门专业 ≥ 70 | 中级 |
| Master | Associate + 2 门专业 ≥ 80 + 10 年经验 + 履历审核 | 高级 |
| Fellow | 25 年经验 + 行业提名 | 顶级 |

**专业方向**（必须选 ≥ 1 门）：
1. Data Governance 数据治理
2. Data Architecture 数据架构
3. Data Modeling 数据建模
4. Data Quality 数据质量
5. Data Integration 数据集成
6. Metadata 元数据
7. Data Security 数据安全
8. Data Warehousing 数据仓库
9. Reference & Master Data 主数据
10. Data Science 数据科学

> 报考建议：考完 CDGP 后（约 2028 年）直接冲 CDMP Practitioner（Data Governance 方向），把已有 DMBOK 知识直接迁移，复习周期可压缩到 60 天。
