# 公众号推文监控 · 使用说明

目标：把**考证（DAMA / 数据治理）** 与 **考博（上海交大在职博士）** 相关的**官方 + 知名第三方**公众号文章**持续关注**下来，在网站里**一字不落**地读，并能标记已读；精选**适合看的**文章**按天混排进「📅 每日学习中心」**，让你每天读一篇。

## 文件
- `articles.js` —— 文章数据库（`window.ARTICLES` + `window.SOURCES`）。网站直接读取它渲染，离线可用。
- `harvest_articles.py` —— 抓取脚本：用搜狗微信公开检索，做**两件事**——① 关键词发现新文；② **按账号定向跟踪**已精选的知名公众号，把新文章合并进 `articles.js`，并产出 `window.SOURCES`（关注源清单）。
- `com.barbara.dama-news.plist` —— macOS 定时任务（**每天 09:00 与 20:00 各跑一次**，贴近实时）。
- `harvest.log` / `harvest.err` —— 自动运行的日志。

## 三件事的分工

| 事 | 谁做 | 怎么做 |
|---|---|---|
| **发现新文章 + 跟踪已知账号**（元数据+摘要） | 脚本自动（launchd 每天 2 次） | ① 关键词检索 → 去重；② 逐个搜索精选账号名 → 模糊匹配 `account` 字段 → 去噪 → 写入 `articles.js`，标记未读 🆕 |
| **逐字全文**（一字不落） | AI（WebFetch，真实浏览器） | 你说「刷新全文」，我把新文章的微信原文逐字抓进 `content` 字段 |
| **阅读 + 已读管理** | 你 + 网站 | 打开「📰 公众号推文精选」或「📡 关注源」，展开全文、点「标记已读」 |

> 为什么全文不能全自动？公众号有反爬验证码，脚本（urllib）会被拦；只有带真实浏览器的 WebFetch 能稳定取全文，而它无法在后台定时跑。所以**发现/跟踪**全自动、**全文**按需补，是当下最稳的架构。

## 实时跟踪设计（关注源）

不只是官方号，还**精选出一批知名、干货多**的第三方号一起跟踪：

- `harvest_articles.py` 内置 `ACCOUNTS`（约 30 个，每个含 `搜索名 / 方向 cat / 展示名`）。
  - 考证：DAMA中国、MyDAMA、数据治理研究院、数据学堂、DATABOK数博库、光环国际、立言研究院、数据要素社、御数坊、志明与数据、金子说数据、CDO首席数据官、大数据DT ……
  - 考博：上海交通大学研究生招生办、上海交大研究生教育、上海交通大学继续教育学院、考博圈、学术志、青塔、读博前线、学术之路、博士号、问津学术圈、高校硕博讯、工程博士申请服务 ……
- **跟踪方式**：对每个账号名在「最近 150 天」窗口内搜狗检索 → 仅保留 `account` 字段**模糊匹配**该账号名的文章（`fuzzy()` 会剥离 官方/公众号/中心/学院/大学 等后缀做双向子串匹配）→ 过 `useful()` 精选过滤。
- **精选过滤 `useful(title, digest, cat)`**：丢弃 招人/招募/招聘/征稿/课程/VIP/讲座/保过 等广告噪音；考证须提及 数据治理/数据资产/CDGA/DAMA 等实质内容；考博须提及 博士/招生/复试/推荐信/导师/学历认证，且过滤掉 卫星/通报/逝世/社会新闻 及**其他院校**简章（除非是通用考博策略）。
- **海外降级 `region_for(title, cat)`**：仅作用于 `cat==='考博'`。标题命中强国外-system 信号（英国/美国/加拿大/澳洲/欧洲/新加坡 +「博士」、香港中文大学、国外博士、留服、学历认证、海外学历、国(境)外学历、境外学历、出国读博）即标记 `region:'overseas'`，从每日核心流降级到「拓展 · 海外」。**刻意不**误伤纯 推荐信/套磁 手艺文（其标题不含上述词，国内外通用，保留在核心流——交大申请-考核制也要套磁、也要 2 封专家推荐信）。导出时对所有条目**自愈式重算** `region`，保证下次抓取不被覆盖。
- **`window.SOURCES`**：每个被命中的账号导出 `{ name, cat, count, latest, accounts[] }`，供「📡 关注源」页渲染。

### 网站里的「📡 关注源」页
- 顶部统计：关注源总数 / 考证源数 / 考博源数 / 最后更新时间。
- 分轨筛选：全部 / 🎓 考证 / 🏛️ 考博。
- 每张源卡片：源名 + 方向标签 + 命中文章数 + 该源**最新一篇**文章（标题/日期），点击「查看该方向全部」跳到推文页按 `cat` 筛选。
- ⚠️ 已知现象：搜狗对「账号名检索」会返回该号的**代表性旧文**（不一定是真·最新），所以 `SOURCES.latest` 显示旧日期属正常，不代表跟踪失效；真正的新文会经 `account` 模糊匹配进 `ARTICLES`。

## 启用每天自动抓取（一次性）
```bash
launchctl load ~/Library/LaunchAgents/com.barbara.dama-news.plist
```
> 已配置为**每天 09:00 与 20:00 各一次**（在 plist 的 `StartCalendarInterval` 数组中），比单次日更贴近实时。
想停用：`launchctl unload ~/Library/LaunchAgents/com.barbara.dama-news.plist`

## 手动跑一次
```bash
cd /Users/barbara/Documents/vscode/test_preparing/资料
python3 harvest_articles.py
```

## 让 AI 补全文
新文章入档后 `content` 默认空，卡片显示「（暂无全文，点「阅读原文」查看）」。
在对话里说「刷新全文」或「把新文章全文抓一下」，AI 会用 WebFetch 逐字抓取并写回 `articles.js`。

## 网站里的操作
推文页（📰 公众号推文精选）：
- 顶部统计：**N 篇文章 / M 篇未读 / 最后更新时间**
- **分轨筛选**：全部 / 🎓 考证 / 🏛️ 考博 / 🌏 拓展 · 海外（`overseas` 分类，按 `region` 字段）
- **只看未读** 按钮：过滤掉已读，专看没看的
- 每篇卡片：**📖 展开全文**（一字不落）/ **✅ 标记已读** / **阅读原文 ↗**（微信原文）
- 标签筛选：考试时间 / 认证体系 / 含金量 / 备考经验 / 考试形式 / 费用 / 有效期
- 已读状态存在浏览器 `localStorage`（key `cdga-news-seen`），换电脑不共享。

关注源页（📡 关注源）：
- 顶部统计：关注源总数 / 考证源 / 考博源 / 更新时间
- 分轨筛选：全部 / 🎓 考证 / 🏛️ 考博
- 源卡片：源名 + 方向标签 + 命中数 + 该源最新文章，`查看该方向全部` 跳推文页按 cat 筛选。

每日学习中心（📅 每日学习中心）：
- 每日卡片底部新增「📰 今日推文」块：**考证 / 考博 轮流**取出一篇（按天序号稳定）。
- 含分轨标签、公众号、日期、「重要信息提取」摘要、可展开的**全文（一字不落）**。
- 点「✅ 标记已读」即同步到推文页未读计数；点「展开全文」看完整正文或「阅读原文」跳微信。
- 随着文章库增长，每日那一篇会自然轮转，保证两类都读到。
